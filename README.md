# Human Typer

Paste text, press **Start**, click into a Google Doc (or anything else) during the countdown, and it gets typed out like a person would: varying speed, pauses after sentences, and the occasional typo that gets backspaced and fixed.

## Windows (no Python needed)

1. Go to **Releases → Human Typer (latest Windows build)** and download `HumanTyper.exe`.
2. Double-click it. Windows may say *"Windows protected your PC"* because the app isn't signed — click **More info → Run anyway**.

## Mac

1. Double-click `Start Typer.command`. The first run sets itself up (needs Python 3 from python.org).
2. The first time, allow **Terminal** under **System Settings → Privacy & Security → Accessibility**, then start it again.

## Stopping it

- **Cmd+Shift+9** (Mac) / **Ctrl+Shift+9** (Windows), or **Esc**
- The **Stop** button
- Move the mouse into the **top-left corner** of the screen

While you hold Cmd/Ctrl/Option/Alt the typer waits, so its letters never turn into shortcuts.

## Settings

| Slider | What it does |
| --- | --- |
| Speed (WPM) | Average typing speed; each keystroke varies around it |
| Typos | How often it hits a neighbouring key and corrects it |
| Thinking pauses | How often it stops for a few seconds after a sentence |
| Countdown | Seconds you get to click into the doc after pressing Start |
